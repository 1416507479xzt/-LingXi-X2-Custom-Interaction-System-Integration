## 不应照抄的异常

约01:00画面中，停止命令返回success，启动命令却返回：

```text
500 Server Error: Internal Server Error
Process "agent" already running
```

这不是“启动成功”。视频没有展示该错误的处理或模式生效的独立语音检查，不能推断进程管理行为、模式是否因自动拉起而生效，也不能据此推荐杀进程或反复重启。后续实际遇到同样错误，应保留输出、只读查询 `aima em get-app agent` 并核对现场行为；当前README标准流程要求每一步成功再继续。

后续自研运行日志和反馈表显示，不能补足前面缺失的重启成功证据。此前成功切换与恢复normal的单独用户实测仍保留在[11月8日记录](2026-11-08-x2-real-robot-integration.md)。
